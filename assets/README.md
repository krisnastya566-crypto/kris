# Assets для Shrek's Swamp Adventure

Сюда нужно положить картинку Шрека.

## Как загрузить

1. Зайди в эту папку на GitHub: `assets/`
2. Нажми **Add file** → **Upload files**
3. Загрузи PNG-картинку Шрека (желательно с прозрачным фоном)
4. Назови файл **`shrek.png`** (важно — именно так)
5. Commit changes

После этого игра в `shrek-game.html` автоматически подхватит твоего Шрека.

Если файла `shrek.png` нет — игра использует запасного Шрека, нарисованного через код (зелёный, с ушками-трубочками, в жилетке).
